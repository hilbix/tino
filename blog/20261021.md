# Hinweise

Die Katastrophale Lücke in PHP betraf alle meine Server.  Alle?  Nein, ein Server läuft weiter: SUSI

SUSI ist ein System, das so alt ist, dass es "neumodische" Software wie PHP nicht verwendet, da es älter ist als diese.
Weshalb es der einzige Service ist, der bei mir derzeit weiterläuft, bis ich die Zeit gefunden habe, alles zu patchen und zu prüfen.

Dieser Eintrag hier dient außerdem meiner Gedächtnisstütze, dass heute einer dieser Tage war, an denen alles schiefgeht.
Nicht nur bei mir.  Weltweit.  Und ich befürchte, das wird nicht das letzte Mal sein, dass wir soetwas erleben.
